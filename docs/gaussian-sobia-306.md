# 공식 306의 SOBIA 표정·끄덕임 검증

2026-11-11. 비교 기준은 로컬 SOBIA-Unity의 `b4ee194b`에 포함된 `RealtimeSemanticEmpathyClassifier`, `EmpathicEmotion.Trajectories`, `EmpathicEmotion.Companion`, `EmpathicNodding`과 `NoddingPolicy`다.

## 테스트 방법

1. `/gaussian`에서 기본 아바타 **GaussianAvatars · 공식 306 · 실시간**을 선택한다. 연결 전에 **끄덕이기**를 연속으로 눌러 한 동작이 진행되는 동안 두 번째 요청이 어떻게 처리되는지 확인할 수 있다.
2. **실시간 대화**에서 **Auto**와 **SOBIA 기본 움직임**을 켠다. 대화 행동과 태도는 기존 Realtime 도구 호출에서 받아 오며, 신뢰도 기준은 0.62다. 대답이 실제로 재생될 때 표정을 적용한다. 짧은 쉼과 지속 발화에 대한 경청 끄덕임은 마이크 입력으로 시험한다. 텍스트 입력으로는 응답 시작과 LLM의 행동 요청을 시험할 수 있다.
3. **WAV 감정 테스트**에서 같은 파일·강도·생동감을 유지하고 감정만 바꿔 재생한다. 발화 중 **끄덕이기**도 시험할 수 있다. 기쁨·슬픔 같은 수동 프리셋은 해당 감정을 고정하고 A2F 발음과 표정 강세를 합성한다.
4. **실행 진단**에서 현재 표정, 끄덕임 계기와 단계, 머리 제어값, 실제 표시된 공식 GPU 프레임의 목 각도·몸통 루트 각도·고정점 변위를 확인한다.

## 구현과 측정 범위

- SOBIA의 9개 시간 변화 표정과 관계 회복·안전 대응을 Gaussian 얼굴 채널에 대응시켰다. 표정 전환, 강세, 쉼, 눈 깜빡임은 브라우저 재생 시계에서 합성한다. CC 리그와 FLAME의 표정 축은 다르며, 미간 압축의 하강 성분은 눈썹 하강 채널을 쓴다. 자동 판단은 이 프로젝트의 Realtime 도구 호출을 사용한다.
- 짧은 쉼은 유성음 0.65초 이상 이후 0.35~2초에 검출한다. 지속 발화는 1.6초부터 검출하며 재후보 간격은 6초다. 경청, 응답 시작, LLM, 수동 요청이 하나의 승인 상태를 공유한다. 최소 승인 간격은 2.2초다. 단일 끄덕임은 15°·1.1초, 이중 끄덕임은 최대 5°·회당 0.4초다.
- 공식 306은 FLAME 루트 회전을 0으로 두고 목 관절을 구동한다. 중립 좌표에서 목 아래 몸통점을 고정하고 옷깃 주변의 위치·회전·크기를 부드럽게 연결한다. 보정 및 아래 수치는 공식 306에 적용된다.
- RTX 5090에서 동일한 15° 숙임을 비교했다. 독립 어깨 검증점 9,012개의 이동거리 p95는 기존 전신 회전 25.01mm, 목 관절만 사용하면 6.94mm였다. 보정 후 같은 점들의 최대 이동거리는 0mm, 코 부근의 평균 하강은 30.83mm였다. 7가지 자세의 어깨 전경 16,144픽셀과 연속 75프레임을 별도로 검사했다.
- 브라우저에서 Ash WAV 4.6초를 강도 80%로 두 번 재생했다. 같은 입력 해시와 각 139개 음성 애니메이션 프레임을 확인했다. 표시된 발화 프레임에 보낸 왼쪽 미소/입꼬리 하강 계수의 표본 최댓값은 기쁨 0.95/0.00, 슬픔 0.00/0.82였다. 이 수치는 렌더러 입력 계수다. 얼굴 근육 움직임의 지각 강도는 측정하지 않았다.

## 기록 비교

기록은 `data/gaussian/sessions/<id>/`에 남는다. **테스트 요약**과 **로그 다운로드**는 서버 재시작 후에도 열린다. 연결 전 수동 테스트는 마지막 입력 후 6초까지, 연결한 테스트는 세션 동안 기록한다. 약 10Hz로 수집한 표본에는 표시한 프레임과 요청 단계의 구분, 프레임 번호, 컨트롤 설정, 원본 A2F 계수와 합성 계수가 들어 있다. 화면이 숨겨지거나 렌더링이 지연되면 같은 표시 프레임이 여러 표본에 들어갈 수 있다. 끄덕임의 승인·거절·시작·종료는 독립 이벤트로 기록한다.

같은 아바타 및 WAV 해시를 확인한 뒤 아래와 같이 두 세션을 비교한다. `--json`으로 발화별 계수 범위와 설정 변경 내역을 확인할 수 있다. 과거 세션에서 기록하지 않았던 값은 비어 있다.

```powershell
.venv/Scripts/python.exe workers/gaussian_lab/compare_sessions.py <session-id-1> <session-id-2>
docker exec gaussian-official-live python /workspace/workers/gaussian_lab/validate_official_neck.py --check-live
```
